# Animal Sounds - Privacy Policy

This repository hosts the official Privacy Policy for the Android application **Animal Sounds** (`com.mouse.sounds`) by **Green Mouse**.

### Web URL
The privacy policy is published via GitHub Pages at:
[https://dziher11.github.io/AnimalSounds/](https://dziher11.github.io/AnimalSounds/)

---

### Key Points
- **Zero data collection:** The app does not collect, store, or share any personal data.
- **Offline operation:** The app functions 100% offline with no network requests.
- **Zero permissions:** No device permissions are requested or used.
- **Child-safe & COPPA compliant:** Fully compliant with Google Play Designed for Families and COPPA policies.
- **No ads:** 100% free of advertising and third-party trackers.
